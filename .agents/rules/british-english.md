# British English Language Requirement

Always write all content, blog posts, documentation, comments, and agent responses in **British English (en-GB)**. Never use American English.

## Guidelines & Spelling Conventions:
- Use `-ise` / `-isation` instead of `-ize` / `-ization` (e.g. *optimise*, *customisation*, *realise*, *prioritise*, *organisation*).
- Use `-our` instead of `-or` (e.g. *colour*, *behaviour*, *favourite*, *flavour*).
- Use `-re` instead of `-er` where applicable (e.g. *centre*, *theatre*).
- Use double consonants where appropriate (e.g. *focussed*, *focussing*, *travelling*, *modelled*).
- Use `-yse` instead of `-yze` (e.g. *analyse*, *paralyse*).
- Use British vocabulary where appropriate (e.g. *programme* for schedules/schemes, *queue* instead of *line* when describing waiting).
